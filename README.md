# ApplePayAPI

Apple Pay integration solution with Spring Boot backend and JavaScript frontend.

## Features
- Merchant validation
- Payment authorization
- Apple Pay for Web integration
- Domain verification support

## Setup
1. Configure your Apple Merchant ID
2. Set up domain verification
3. Configure Stripe keys
4. Deploy with HTTPS

## Requirements
- Java 11+
- Spring Boot 2.7+
- Apple Developer Account
