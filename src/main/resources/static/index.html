Available API Endpoints

Apple Pay Endpoints

POST /api/applepay/validate-merchant - Validate Apple Pay merchant

GET /api/applepay/pkpass/download - Download Apple Wallet pass
GET /api/applepay/test-validation - Test merchant validation
GET /api/applepay/test - Test endpoint

KBAN Endpoints

GET /api/kban/ll5 - KBAN LL5 endpoint
POST /api/kban/validate - Validate KBAN
GET /api/kban/export - Export KBAN data
